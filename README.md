# RexeWare 1.20.1

Fabric mod, Minecraft 1.20.1, Java 17. Fabric API ayrica kurulmalidir.

ClickGUI: `R` tusu ile acilir ve kapanir (tus Ayarlar > Kontroller > RexeWare altindan degistirilebilir).
Sol tik: modulu ac/kapat. Sag tik: modulun ayarlarini ac. Panel basligindan surukleyerek tasinir.

Derleme: GitHub -> Actions -> Build -> Run workflow, jar `Artifacts` icinde.
Yerelde: `./gradlew build`, jar `build/libs/` icinde.
